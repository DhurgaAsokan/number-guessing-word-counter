# Number Guessing Game & Word Counter

A simple web app built with HTML, CSS and JavaScript.

## Features
- Number guessing game with 3 levels (Easy, Medium, Hard)
- Random number generation
- Attempts counter and scoring system
- Word counter for uploaded .txt files or pasted text
- Word frequency analysis (total words, unique words, longest word, top 5 words)
- Input validation

## How to Run
Download the files and open `index.html` in your browser.
